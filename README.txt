FREE PUBLISHING WITH GITHUB PAGES
1. Create a free GitHub account.
2. Create a new PUBLIC repository named: braydens-learning-adventure
3. Upload every file and folder from this package.
4. Open Settings → Pages.
5. Under “Build and deployment,” choose “Deploy from a branch.”
6. Choose branch “main” and folder “/(root),” then Save.
7. GitHub will show the free website address after deployment.

ADD TO IPAD HOME SCREEN
1. Open the published website in Safari.
2. Tap the Share button.
3. Tap “Add to Home Screen.”
4. Tap Add.

Progress is saved in the browser on that iPad. Clearing Safari website data or using a different browser/device can reset local progress.
